Über Tapetum

Licht sehen, bevor es leuchtet.

Über das Projekt

BlinderKitten ist eine freie Lichtsteuerung, mit der sich ganze Theaterproduktionen fahren lassen. Was fehlte, war eine Visualisierung, die genau dazu passt: frei, schlank, ohne Export und ohne zweite Patchliste – und mit dem Bühnenbild, das man ohnehin in IngeTrazo zeichnet. Tapetum liest beide Dateien direkt, empfängt das Art-Net von BlinderKitten auf demselben Rechner und zeigt, wie das Licht auf der Bühne aussehen wird. So lassen sich Stimmungen, Positionen und Umbauten vorbereiten, bevor man im Saal steht.

Der Name kommt vom Tapetum lucidum, der Schicht hinter der Netzhaut von Katzen, die das Licht zurückwirft – deshalb leuchten ihre Augen im Scheinwerferlicht. BlinderKitten, die Katze, das Licht: das passte.

Mit KI programmiert

Tapetum ist vollständig „vibecoded“: Jede Zeile Code hat Claude Code (Anthropic) geschrieben. Ich habe beschrieben, was die Software können soll, die Ergebnisse geprüft, verworfen, nachgeschärft und im Alltag ausprobiert. Das Logo hat ChatGPT generiert. Ohne KI gäbe es Tapetum in dieser Form nicht – in einem Bruchteil der Zeit ließen sich Dinge wie Strahlen im Haze, Gobos auf Gaze oder die direkte Anbindung an BlinderKitten umsetzen.

Der Quelltext ist offen (MIT-Lizenz). Fehler und Ideen meldest du gern per Mail oder auf GitHub.

About Tapetum

See the light before it shines.

About the project

BlinderKitten is a free lighting controller that can run entire theatre productions. What was missing was a visualizer to match: free, lean, without export and without a second patch list – and with the set you draw in IngeTrazo anyway. Tapetum reads both files directly, receives BlinderKitten's Art-Net on the same computer and shows how the light will look on stage. That way looks, positions and set changes can be prepared before you are in the venue.

The name comes from the tapetum lucidum, the layer behind a cat's retina that throws light back – that's why their eyes glow in a spotlight. BlinderKitten, the cat, the light: it fitted.

Written with AI

Tapetum is entirely “vibe-coded”: every line of code was written by Claude Code (Anthropic). I described what the software should do, checked the results, threw things out, sharpened them and tried them out in practice. The logo was generated by ChatGPT. Without AI, Tapetum wouldn't exist in this form – things like beams in haze, gobos on gauze or the direct link to BlinderKitten became possible in a fraction of the time.

The source is open (MIT License). Bugs and ideas are welcome by email or on GitHub.
